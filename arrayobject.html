1. map() — Har Element Ko Transform Karna map() poore array ke har element pe kuch operation karta hai, aur naya array return karta hai (original nahi badalta).

Samjho Kaise Kaam Karta Hai: map() har element (1, 2, 3, 4) ko function ke andar bhejta hai Function jo bhi return kare, wahi naye array mein jata hai 1 → 2, 2 → 4, 3 → 6, 4 → 8 → naya array [2, 4, 6, 8]

2. filter() — Condition Ke Hisaab Se Naya Array Banana filter() har element ko check karta hai, aur sirf wo elements rakhta hai jo condition true ho — baaki hata deta hai.

3. reduce() — Poore Array Ko Ek Single Value Mein "Reduce" Karna reduce() sabse tricky hai, lekin bahut powerful. Ye poore array ko combine karke ek final value banata hai (jaise total sum, ya average).

Samjho Kaise Kaam Karta Hai: accumulator — "abhi tak ka total" (jaise humara count variable tha!) current — array ka current element 0 — starting value (accumulator yahi se shuru hota hai) Trace Karo: Start: accumulator = 0 current = 10 → 0 + 10 = 10 → accumulator ban gaya 10 current = 20 → 10 + 20 = 30 → accumulator ban gaya 30 current = 30 → 30 + 30 = 60 → accumulator ban gaya 60 current = 40 → 60 + 40 = 100 → accumulator ban gaya 100

Important Samjho: reduce() sirf ek final value print/return karta hai (jo console.log(totalPrice) mein aayegi), teen alag lines nahi. Tumne jo "100, 300, 450" bola — wo internal steps the (jo maine trace kiya), lekin actual output sirf 450 hoga, kyunki console.log sirf ek baar chal raha hai, reduce() ke poora complete hone ke baad.
