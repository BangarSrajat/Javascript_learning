# JavaScript Complete Cheat Sheet (Interview Revision) ## 1. Variables & Data Types ```javascript let age = 25; // Number let name = "Rahul"; // String let isActive = true; // Boolean let empty = null; // Null let notSet; // Undefined let PI = 3.14; // const use karo jab value fixed ho ``` **Rule:** `let` value badle to, `const` fixed value ke liye. `var` kabhi mat use karo. --- ## 2. Operators ```javascript 5 === "5" // false (value + type dono check) 5 == "5" // true (sirf value check) age >= 18 // "ya usse zyada" wale case mein age > 18 // "sirf se zyada" wale case mein (boundary exclude) a && b // dono true chahiye a || b // koi ek true kaafi !a // ulta karta hai ``` --- ## 3. Conditions ```javascript if (marks >= 90) { console.log("A"); } else if (marks >= 60) { console.log("B"); } else { console.log("Fail"); } switch (day) { case 1: console.log("Mon"); break; default: console.log("Invalid"); } let result = age >= 18 ? "Adult" : "Minor"; // Ternary ``` --- ## 4. Loops ```javascript for (let i = 0; i < 5; i++) { console.log(i); } let i = 0; while (i < 5) { console.log(i); i++; } do { console.log(i); i++; } while (i < 5); // ARRAY LOOP RULE: hamesha < use karo, kabhi <= nahi for (let i = 0; i < arr.length; i++) { } ``` --- ## 5. Strings ```javascript str.length // kitne characters str.toUpperCase() // CAPITAL str.toLowerCase() // small str.includes("text") // true/false str.indexOf("text") // position ya -1 str.slice(0, 4) // part nikalna (start include, end exclude) str.trim() // extra spaces hatana str.split(" ") // array mein todna str.replace("a", "b") // replace karna `Hello ${name}` // template literal ``` --- ## 6. Numbers/Math ```javascript Math.round(4.5) // 5 (nearest) Math.floor(4.9) // 4 (hamesha neeche) Math.ceil(4.1) // 5 (hamesha upar) Math.random() // 0 se 1 ke beech Math.max(1,5,3) // 5 num.toFixed(2) // decimal fix karna ``` --- ## 7. Functions ```javascript function add(a, b) { return a + b; } const add = (a, b) => a + b; // Arrow function function greet(name = "Guest") { // Default parameter console.log("Hello " + name); } ``` **Rule:** Function ek jagah use ho to andar likho, multiple jagah use ho to bahar banao. --- ## 8. Objects ```javascript let user = { name: "Rahul", age: 25 }; user.name // dot notation se access user.city = "Indore"; // nayi property add delete user.age; // property delete // Destructuring let { name, age } = user; ``` --- ## 9. Arrays ```javascript let arr = [1, 2, 3]; arr.push(4); // end mein add arr.pop(); // end se remove arr.unshift(0); // shuru mein add arr.shift(); // shuru se remove arr.includes(2); // true/false arr.indexOf(2); // position arr.slice(1, 3); // copy (original safe) arr.splice(1, 2); // original modify arr.sort((a,b) => a-b); // numbers ascending arr.sort((a,b) => b-a); // numbers descending arr.reverse(); // Spread operator (safe copy) let copy = [...arr]; ``` --- ## 10. Array of Objects ```javascript let students = [ { name: "Rahul", marks: 85 }, { name: "Priya", marks: 92 } ]; students[0].name // "Rahul" for (let i = 0; i < students.length; i++) { if (students[i].marks >= 60) { console.log(students[i].name); } } ``` --- ## 11. map(), filter(), reduce() ```javascript let nums = [1, 2, 3]; nums.map(n => n * 2); // [2, 4, 6] - transform nums.filter(n => n > 1); // [2, 3] - condition se filter nums.reduce((acc, curr) => acc + curr, 0); // 6 - combine to ONE value ``` **Yaad Karo:** `count = 0` sirf tab jab "kitne/total" NUMBER chahiye ho. --- ## 12. Error Handling ```javascript try { console.log(undefinedVar); } catch (error) { console.log("Error: " + error.message); } ``` --- ## 13. DOM ```javascript document.getElementById("id") document.querySelector("#id") // CSS-style document.querySelectorAll(".class") // sabhi matches element.textContent = "text"; element.innerHTML = "bold"; element.style.color = "red"; element.classList.add("active"); element.classList.remove("active"); element.classList.toggle("active"); let newEl = document.createElement("li"); newEl.textContent = "New Item"; parent.appendChild(newEl); element.addEventListener("click", function() { console.log("Clicked!"); console.log(this); // 'this' = jispe event laga hai }); ``` **Events:** `click`, `keyup`, `mouseover`/`mouseout`, `change`, `submit` **RULE:** Event hamesha us element pe lagta hai jispe interaction hoga. --- ## 14. JSON ```javascript let jsonString = '{"name": "Rahul"}'; let obj = JSON.parse(jsonString); // String → Object let str = JSON.stringify(obj); // Object → String ``` --- ## 15. Async JavaScript ```javascript // Promise let myPromise = new Promise((resolve, reject) => { if (success) resolve("Done!"); else reject("Failed!"); }); myPromise.then(result => console.log(result)) .catch(error => console.log(error)); // Fetch fetch("https://api.example.com/data") .then(response => response.json()) .then(data => console.log(data)) .catch(error => console.log(error)); // Async/Await async function getData() { try { let response = await fetch("url"); let data = await response.json(); console.log(data); } catch (error) { console.log(error); } } ``` --- ## 16. Closures ```javascript function createCounter() { let count = 0; return function() { count++; return count; }; } let counter = createCounter(); counter(); // 1 counter(); // 2 ``` **Definition:** Inner function, outer function ke variables ko "yaad" rakhta hai, chahe outer function khatam ho chuka ho. --- ## 17. Stack vs Heap Memory ```javascript // Stack (Primitives) - VALUE copy let a = 10; let b = a; b = 20; console.log(a); // 10 (safe) // Heap (Objects/Arrays) - REFERENCE copy let arr1 = [1, 2]; let arr2 = arr1; arr2.push(3); console.log(arr1); // [1, 2, 3] - dono badle! // Safe copy ke liye let safeCopy = [...arr1]; ``` --- ## Common Mistakes Checklist (Interview Se Pehle Check Karo) - [ ] `let`/`const` likhna nahi bhoole? - [ ] Variable naam consistent hai poore code mein? - [ ] Array loop mein `<` use kiya, `<=` nahi? - [ ] `===` use kiya, `==` nahi? - [ ] Function ke andar khud ko call to nahi kar diya? (infinite loop) - [ ] Event sahi element pe laga hai (jispe interaction ho)? - [ ] `+=` chahiye tha ya `=` use kar diya? --- ## Interview Ke Liye Golden Rule > **"Concept clear hai to syntax approx bhi chalega. Interviewer LOGIC dekhta hai, perfect syntax nahi."** Agar bhool jao exact method name, bolo: *"Iske liye ek array method hai jo... (jo karna hai wo describe karo)"* — interviewer khud bata dega ya samajh jayega tumhe concept aata hai.
