Async JavaScript Kya Hai? (Recap)

JavaScript is a single-threaded language, meaning it executes one task at a time. However, when there's a time-consuming task (like fetching data from a server, or a timer), JavaScript doesn't wait — it sends that task to run in the background and continues executing the rest of the code. Once the background task completes, its result is handled later. This behavior is called Asynchronous programming." Yaad hai humne Timer (setTimeout) mein dekha tha — JavaScript wait nahi karta, aage badhta rehta hai? Ye hi "Asynchronous" behavior hai.

1. Promises — Kya Hai? Promise ek "vaada" hai — JavaScript future mein kabhi result dega, abhi turant nahi. Simple Analogy: Socho tumne Swiggy pe order kiya. Turant khana nahi milta — company tumhe ek "promise" deti hai ki "khana aayega". Ye promise 2 tareeke se khatam ho sakta hai: Success (khana mil gaya) — isse "Resolved" kehte hain Failure (order cancel ho gaya) — isse "Rejected" kehte hain

2. Promise Kya Hai? "Promise ek JavaScript object hai jo future mein milne wale result ka "vaada" represent karta hai. Ye 3 states mein hota hai: Pending — abhi result nahi aaya, wait ho raha hai Resolved/Fulfilled — task successfully complete hua Rejected — task fail hua, error aaya .then() se hum success case handle karte hain, .catch() se error/failure case handle karte hain." 3. fetch() Kya Hai? "fetch() ek built-in JavaScript function hai jo server se data mangne (API call karne) ke liye use hota hai. Ye ek Promise return karta hai. Server se response JSON format mein aata hai, jise humein .json() method se JavaScript Object mein convert karna padta hai, taaki hum data use kar sakein." 4. .then() Aur .catch() Mein Kya Farak Hai? ".then() tab chalta hai jab Promise successfully resolve ho jata hai — matlab kaam sahi se complete hua. .catch() tab chalta hai jab kuch galat ho jaye (error aaye, ya Promise reject ho) — isse hum errors ko gracefully handle karte hain, taaki poora program crash na ho." 5. JSON Kya Hai? "JSON (JavaScript Object Notation) ek lightweight data format hai jo data ko text/string ke roop mein represent karta hai. Ye server aur client ke beech data transfer karne ke liye most common format hai, kyunki ye language-independent hai — har programming language JSON ko samajh sakti hai."
